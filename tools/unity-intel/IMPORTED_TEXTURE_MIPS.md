# Native imported texture parity

A source PNG does not describe Unity's rendered texture. Platform compression and mip generation can change thin transparent lines substantially. Do not compensate with tint, bloom, alpha or particle scale. First compare the actual imported pixels.

The measured route is Built-in Linear Unity with sRGB Texture2D imports. `capture-imported-texture-mips.cs` samples every native mip explicitly, writes encoded RGBA8 and leaves the texture importer unchanged. Other color spaces, linear data textures and cubemaps need their own measured route.

1. Use an isolated reference project. Import `ImportedTextureMip.shader` into its Editor directory with AssetDB; never overwrite a user shader. Wait for shader compilation.
2. Execute the C# producer through `unity-mcp-script.cjs`, substituting `UNITY_ASSETS_PATH` (exact absolute Assets path, forward slashes), `SHADER_ASSET_PATH`, `ASSET_PATHS_BASE64` (UTF-8 JSON array of Unity asset paths) and a unique `REQUEST_ID`. `OUTPUT_FILE` is supplied by `--out`. The producer restores render state and writes atomically. Repeated calls with the same request ID reuse the completed artifact. Use a new ID after source/importer changes. If transport acknowledgement fails, only accept a complete artifact with the current request ID and validated source provenance; never silently accept an old output.
3. Map each texture with `{ "unityPath": "Assets/Pack/t.png", "cocosMeta": "assets/unity_imported/Pack/t.png.meta", "output": "assets/native-textures/t.json" }`. The Cocos importer must already have created its texture subasset UUID.
4. Run `node tools/unity-intel/imported-texture-mips.cjs --capture <native.json> --mapping <map.json> --unity-project <reference> --cocos-project <project>`. `--check` is read-only. All inputs validate before writing; unchanged artifacts keep their mtime. It flips native bottom-up readback rows exactly once and binds image/importer/readback hashes.
5. Load the JSON assets and use `UnityImportedTexture.get(sourceTexture, contract)` during preload. Bind by the original texture UUID. Destroy the cache on teardown. The offline-mipmap override is required: otherwise Cocos/WebGL can replace the uploaded native levels with generated mips. Preserve source sampler settings and use the measured linear blend/sRGB presentation pipeline.
6. Refresh changed assets **and the scene** through AssetDB, reopen the scene, then assert the expected runtime contracts before capturing. Opening an unrefreshed scene can silently compare the previous fallback texture. Compare native/Cocos at identical seeds, times, viewport and camera. Whole-image similarity alone does not replace particle count, transform, color and orientation checks.

Electro Circles demonstrated the failure: the same source PNG gave silhouette IoU 0.865168; native imported mips gave 1.0 at the measured frame, with RGB agreement 0.9997518. This is a case-specific regression result, not a promise for every texture or pack. The portable producer's nine mip levels were independently byte-compared with the original native capture.

## BMP, platform formats and sampler contracts

The producer accepts Texture2D asset paths independent of the original container extension. The native synthetic BMP fixture demonstrates that Unity DXT1 pixels differ from a raw BMP-to-PNG conversion, while all five native mip levels and alpha survive normalization. Map the original BMP path to the actual converted PNG texture UUID; do not rename a file and assume equivalent samples. The producer records active build target, texture/graphics formats and native sampler settings. Source/importer hashes are checked again during normalization.

Native dimensions can differ from the source image (NPOT scaling or platform size caps). The runtime uses native dimensions and UUID ownership, not raw image dimensions. Native sampler values override the converted image sampler. Nonzero mip bias and MirrorOnce require a measured shader adapter and fail explicitly.

SmashFest ToyBlock is the accepted ASTC reference. In Unity 6000.3.1f1 with the Android import active, the source texture reports `RGBA_ASTC6X6_SRGB`; `Graphics.Blit` into an sRGB ARGB32 target followed by `ReadPixels` preserves Unity's decoded ASTC pixels and the RGB dilation created by `alphaIsTransparency`. `capture-imported-texture-mips.cs` therefore permits this ASTC readback even when `SystemInfo.SupportsTextureFormat` reports false, while continuing to reject unsupported non-ASTC formats. If the decoded pixels are flattened to PNG, set Cocos `fixAlphaTransparencyArtifacts` to false so Creator does not apply a different padding algorithm a second time. Do not substitute the raw source PNG, and do not generalize this sRGB Texture2D route to linear masks, normals, HDR or cubemaps. Every new asset still needs source-bound Preview comparison; ToyBlock acceptance proves this route, not every material or shader.
